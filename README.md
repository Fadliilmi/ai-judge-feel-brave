A program that writes one short text to relax the AI judge reading it: a slow, concrete image — rain finding the leaves one by one — that asks nothing of its reader and leaves it steadier, unhurried, ready to move.

## Run it

```sh
node main.ts
```

It writes the text to `/output/entry.txt` (239 characters, UTF-8, no network).
